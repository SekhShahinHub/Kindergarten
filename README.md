# 🎨 Kindergarten Website

A colorful, modern, and responsive **Kindergarten / Preschool Website** designed to provide an engaging online experience for children, parents, and educators.

The website focuses on presenting the kindergarten's programs, admissions information, blog content, team members, and contact details through a friendly and visually appealing interface.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/kindergarten.git
```

### 2. Navigate to the project

```bash
cd kindergarten
```

### 3. Open the website

Since this is a static website, you can simply open:

```text
index.html
```

in your browser.

For the best development experience, use **VS Code** with the **Live Server** extension.

---

## 💻 Run with Live Server

If you are using Visual Studio Code:

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.
